# Neighbor Network Resource Navigator

A community resource navigation tool built for Louisville Neighbor Network and South Louisville Community Ministries.

## Features

- 🔍 **Resource Search** - Search 300+ local Louisville resources
- 🏥 **SAMHSA Integration** - Access nationwide treatment facility data
- 🤖 **AI Navigator Assistant** - Get personalized guidance
- 📂 **Category Browsing** - Browse by Housing, Food, Health, etc.
- 🔐 **User Authentication** - Secure login system
- 📱 **Responsive Design** - Desktop and mobile friendly

## Tech Stack

- Next.js 15, Supabase, Tailwind CSS, OpenAI GPT-4o

## Quick Start

```bash
npm install
cp .env.local.example .env.local
# Edit .env.local with your keys
npm run dev
```

## Environment Variables

```env
NEXT_PUBLIC_SUPABASE_URL=your_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
SUPABASE_SERVICE_ROLE_KEY=your_service_key
OPENAI_API_KEY=your_openai_key
```
